By initializing access to the LabGuard terminal, you agree to comply with all security protocols outlined herein. Use of this system constitutes a formal agreement to university infrastructure standards.

Access is restricted to authorized faculty and staff of **Araullo University**.

- **Credential Integrity:** You are responsible for the security of your Access Cipher.
- **Sharing Prohibited:** Credentials are non-transferable. Sharing access keys is a tier-one security violation.

Users must not:

- Attempt to gain unauthorized clearance levels.
- Reverse-engineer security scripts or terminal logic.
- Utilize the system for personal gain or malicious infrastructure manipulation.

The System Administrator reserves the right to:

- Audit all actions performed under any personnel identity.
- Revoke access upon change of employment or faculty status.
